# P1-08A evidence — two-Surface technical spike

Generated by `apps/xr-lab/e2e/multi-surface-spike.spec.ts`, Chromium 159 and
Firefox 159, 1000 × 700 viewport:

```bash
cd apps/xr-lab
P1_08A_EVIDENCE=1 npx playwright test e2e/multi-surface-spike.spec.ts
```

Without `P1_08A_EVIDENCE` (the normal E2E run) the spike writes only to
`test-results/`, so this directory is never overwritten by accident.

**Files:**
- `spike-<browser>.json`: camera, plane poses, and one record per probe. Each
  record has the contract owner, the painted layer (screenshot pixel), the
  `elementFromPoint` owner, the click receiver, and the agreement flags.
- `s<N>[-hole]-<browser>.png`: the page of each scenario, captured before its
  probe click.

**Colors:**
- red: Surface A
- blue: Surface B
- green: the WebGL "Adaptive" panel
- yellow: A's Native element
- grey: canvas

Scenario meanings and results: `docs/p1-08a-multi-surface-architecture.md` §14
and ADR 0002.
